# RAINY VISTA — үнэ, өртөг, кредитийн санал

Шалгасан: 2026-10-15. Дүн нь төлөвлөлтийн тооцоо; төлбөртэй Fal үүсгэлтээр бодит нэхэмжлэхийг хараахан тулгаагүй.

## Нэгж ба томьёо

**1 кредит = 100₮.** Кредит зөвхөн серверийн эрхээр олгогдоно. Бүртгэл үнэ төлбөргүй ч шинэ данс 0 кредиттэй эхэлнэ. Онлайн checkout одоогоор холбогдоогүй; админ төлбөрийг шалгасны дараа цэнэглэнэ. Багцын үнийг баталсан онлайн төлбөр гэж харуулахгүй.

- Монголбанкны 2026-10-14-ний USD ханш: 3,595.99₮. Тооцооны ханш: **3,600₮/$**, банкны бодит картын ханш биш.
- Төлбөр хүлээн авах шимтгэл: борлуулалтын **3% гэсэн таамаг**. Бодит үйлчилгээний гэрээ хараахан сонгоогүй; тогтмол гүйлгээний шимтгэл ороогүй.
- Сервер, хадгалалт, траффикийн нэг үүсгэлтэд ногдох нөөц: **50₮ гэсэн таамаг**. Жишээ нь сарын 100,000₮ зардал / 2,000 үүсгэлт. Railway/Supabase-ийн бодит нэхэмжлэхийг энэ тооцоогоор баталсан гэж үзэхгүй.
- Markup: нийт тооцоолсон өртгийн **70%**, өөрөөр хэлбэл **×1.70**. Энэ нь 70% цэвэр ашгийн margin биш; шимтгэлгүй суурь дээр орлогын ~41.18%-ийн margin болно.

```
C = Fal API өртөг ($) × 3,600 + 50₮
Кредит = ceil( C × 1.70 / (1 − 0.03) / 100₮ )
Борлуулах үнэ = Кредит × 100₮
Төлөвлөсөн үлдэх ашиг = Үнэ × 0.97 − C
```

Кредитийг бүхэл нэгжид дээш тоймлодог тул дээрх таамгуудаар шимтгэлийн дараах markup хамгийн багадаа 70% байна. НӨАТ, орлогын татвар, цалин, маркетинг, төлбөртэй дахин оролдлого болон бага хэрэглээний тогтмол зардлын нөхөгдөөгүй хэсэг үүнд ороогүй. Иймээс 70% цэвэр ашиг баталгаалахгүй. НӨАТ төлөгч бол татварын зөвлөгөөгөөр НӨАТ-ыг тусад нь нэмэх эсвэл суурь томьёонд оруулах шаардлагатай.

## 100 загварын үнэ ба ашиглах эрх

`provider-pricing-source.json` нь 100 албан ёсны Fal model URL-ээс цуглуулсан үнийн тайлбарууд. Нэг хуудсанд ойролцоо endpoint-уудын үнэ хамт байж болох тул цуглуулсан эх сурвалжийг шууд автомат тариф гэж ашиглаагүй.

`model-pricing.csv` нь 100 загварын одоогийн статус болон идэвхтэй загварын бодит adapter тохиргоонд тохирох үнийн тооцоо. Одоогоор **37 загвар** тогтмол/хугацаа/нягтаршлын баталгаажсан дүрэмтэй. Бусад **63 загвар** каталогт үлдэнэ, гэхдээ үнэ баталгаажтал үүсгэлт нь идэвхгүй. Токен, GPU секунд, эх зургийн пиксел, үүсэх давхаргын тоо, эсвэл тодорхой бус тарифыг тогтмол 2/6 кредит гэж үнэлэхгүй. Автомат сонголтын бүх зам үнэтэй загвартай.

Үнэ `lib/pricing.ts` дээр хяналттай хувилбарлагдсан; live billing API гэж үзэхгүй. Анхны дүрмийн эцсийн огноо 2026-11-15: шинэчлээгүй бол төлбөр суутгал зогсоно. Долоо хоног бүр эсвэл Fal үнэ өөрчлөгдвөл тариф, ханш, шимтгэл, бодит хэрэглээний нэхэмжлэхийг тулгаж, version/validUntil-ийг шинэчлэх. Minimax H3 Max-ийн 10-р сарын 15-нд дуусах түр хямдралыг ашиглаагүй; хямдралын дараах үнээр тооцсон.

## Суутгал, буцаалт, хамгаалалт

1. `/api/pricing` нь сонгосон adapter-ийн нэг зураг, эсвэл тодорхой секундын видеоны үнийг харуулна. Зураг 4K/2K, видео хугацаа болон дуугүй тохиргоо үнийн тооцоотой ижил.
2. Үүсгэхэд сервер үнээ дахин тооцно. Клиентийн `expected_credits` ба `pricing_version` зөрвөл шинэ үнийг харахыг шаардаж **кредит суутгахгүй**.
3. Supabase transaction баланс түгжиж, нэг UUID-д нэг удаа үнийн дүнгээр суутгана. Үнийн snapshot тухайн generation дээр хадгалагдана. Browser-оос баланс, үнийн snapshot бичих эрхгүй.
4. Баталгаатай бүтэлгүй generation нэг удаа бүтэн кредит буцаана. Provider-д хүрсэн эсэх нь тодорхойгүй timeout бол давхар хүсэлт явуулахгүй; reconciliation шаардлагатай.
5. Шинэ үнэ хуучин дууссан ажлын суутгал/буцаалтыг өөрчлөхгүй. Шинэ систем эхлэх үед production дээр 0 данс, 0 generation байсан тул хуучин үлдэгдлийг хөрвүүлээгүй.
