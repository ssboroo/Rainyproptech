# RAINY VISTA — 200% markup, үнэ ба кредит

Шалгасан: 2026-10-15. Хувилбар: 2026-10-15.2. Нэг кредит = **100₮**. Доорх нь төлөвлөсөн борлуулах үнэ; бодит Fal нэхэмжлэхтэй тулгах шаардлагатай.

## Өртөг ба ашгийн арга

- Монголбанкны 2026-10-14-ний ханш 3,595.99₮/USD. Борлуулалтын тооцоонд **3,700₮/USD** хэрэглэнэ: банкны хөрвүүлэлт ба ханшийн хэлбэлзлийн ~2.89% нөөц. Энэ нь live банкны ханш биш.
- API өртгийн **5% нөөц**: төлбөртэй алдаа, дахин боловсруулах эрсдэлийн төсөв; бодит failure rate гэж батлаагүй.
- Төлбөр хүлээн авах **3% шимтгэлийн таамаг**. Бодит банк/checkout гэрээгээр солих; тогтмол гүйлгээний хураамж ороогүй.
- Үүсгэлт бүрт **50₮ ажиллагааны нөөц**. Жишээ нь 100,000₮/сар / 2,000 үүсгэлт. Энэ нь Railway/Supabase-ийн батлагдсан нэхэмжлэх биш. Хэрэглээ бага бол уг нөөцийг өсгөх эсвэл тусдаа платформын сарын төлбөр шаардлагатай.
- **200% markup = өртөг × 3**, 200% profit margin биш. Шимтгэлгүй суурь орлогын margin ~66.67%. НӨАТ, орлогын татвар, маркетинг, цалин тооцоонд ороогүй; 200% цэвэр ашиг баталгаалахгүй.

```
C = API ($) × 3,700 × 1.05 + 50₮
Кредит = ceil(C × 3 ÷ 0.97 ÷ 100₮)
Үнэ = Кредит × 100₮
Төлөвлөсөн үлдэх ашиг = Үнэ × 0.97 − C
```

Дээш тоймлолт, төлбөрийн шимтгэлийг нөхсөн томьёо нь дээрх нөөцтэй өртгийн дараа хамгийн багадаа 200% markup хадгална. API $0.56 нь хэрэглэгчийн эцсийн үнэ биш.

## Видео тохиргоо ба шалгалт

- Видеоны уртыг загварын schema-д дэмжигдсэн секундээр сонгоно. Kling 3 Pro / O3 / Native 4K нь 3–15 секунд; бусад загварын бодит хүрээ өөр.
- Нягтаршлын сонголт яг тухайн endpoint-ийн дэмжлэгтэй. Автомат горимд 4K сонгоход native 4K endpoint рүү шилжинэ. 1080p endpoint-д 4K гэж шошго зүүхгүй.
- Дуугүй видео. Дуу, voice control нэмэхэд тусдаа үнэ баталгаажуулах шаардлагатай.
- Кадрын харьцаа эх зургаас хамаарна. MP4-ийн MB хэмжээг урьдчилан батлахгүй; encoder ба хөдөлгөөнөөс хамаарна.
- Видеоны **урт** ба **боловсруулах хугацаа** өөр. API queue/model-оос хамаарч хэдэн минут шаардаж болно; бүх загварт нэг ETA амлахгүй.
- `docs/model-audit.json`: одоогийн 100 endpoint-ийг албан ёсны Fal API/OpenAPI-тай тулгасан. 100 таарсан, 0 schema өөрчлөлт, 0 татаж чадаагүй. Энэ нь төлбөртэй inference/чанарын benchmark биш.
- `tests/video-options.test.ts`: 50 видео adapter-ийн 1,000-аас олон хугацаа/нягтаршлын хослолд input schema шалгаж, үнэтэй хослол бүрийг тооцно.
- **37 загвар** үнийн дүрэмтэй. **63 загвар** токен/GPU/пиксел/тодорхой бус тарифаас шалтгаалж өртөг баталгаажтал идэвхгүй. Тэдгээрт зохиомол тогтмол үнэ тавиагүй.
- Nano Banana Pro: чанарт чиглэсэн 4K рендер. Seedream 5 Pro: 2048² интерьер. Kling 3 Pro / O3: архитектурын зөөлөн хөдөлгөөн. Kling Native 4K: премиум өндөр нягтаршил. Эдгээр нь бүтээгдэхүүний сонголт; өөрийн эх зургаар төлбөртэй A/B benchmark хийх хүртэл “бүгдээс хамгийн сайн” гэж батлахгүй.
- Veo 3.1-ийн албан ёсны хуудсанд 2026-11-17-нд endpoint зогсоох мэдэгдэл байсан тул шинэ анхдагч загвар болгоогүй.

Тарифын дүрэм live billing API биш. `validUntil` 2026-11-15 хүрээд хянаагүй бол шинэ charge зогсоно. Долоо хоног бүр ханш, Fal тариф, бодит нэхэмжлэх, retry хувь болон сарын зардлыг тулгаж version-ийг шинэчлэх.

## Суутгал, буцаалт, хамгаалалт

1. `/api/pricing` нь сонгосон adapter-ийн нэг зураг, эсвэл тодорхой секундын видеоны үнийг харуулна. Зураг 4K/2K, видео хугацаа болон дуугүй тохиргоо үнийн тооцоотой ижил.
2. Үүсгэхэд сервер үнээ дахин тооцно. Клиентийн `expected_credits` ба `pricing_version` зөрвөл шинэ үнийг харахыг шаардаж **кредит суутгахгүй**.
3. Supabase transaction баланс түгжиж, нэг UUID-д нэг удаа үнийн дүнгээр суутгана. Үнийн snapshot тухайн generation дээр хадгалагдана. Browser-оос баланс, үнийн snapshot бичих эрхгүй.
4. Баталгаатай бүтэлгүй generation нэг удаа бүтэн кредит буцаана. Provider-д хүрсэн эсэх нь тодорхойгүй timeout бол давхар хүсэлт явуулахгүй; reconciliation шаардлагатай.
5. Шинэ үнэ хуучин дууссан ажлын суутгал/буцаалтыг өөрчлөхгүй. Шинэ систем эхлэх үед production дээр 0 данс, 0 generation байсан тул хуучин үлдэгдлийг хөрвүүлээгүй.
