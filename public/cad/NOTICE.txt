RAINY VISTA native CAD reader

The independently loaded DWG worker uses @mlightcad/libredwg-web 0.8.0,
a WebAssembly build of GNU LibreDWG, under GNU GPL version 3.
Copyright belongs to the GNU LibreDWG contributors and MLight Lee.
This component is provided without warranty. Full license: /cad/COPYING

Corresponding source, build scripts and changes:
https://github.com/mlightcad/libredwg-web
https://www.gnu.org/software/libredwg/
https://github.com/ssboroo/Rainyproptech/blob/main/public/cad/dwg-worker.js
The upstream JavaScript and WASM binaries are unmodified and copied from the
pinned npm package during build. The worker communicates only via postMessage.
The app's worker configures a 64 MB initial memory allocation, silent logging,
and a same-origin WASM location.

DXF parsing: dxf 5.3.1, MIT, https://github.com/skymakerolof/dxf
SketchUp parsing: openskp 1.3.0, MIT, https://github.com/iamahsanmehmood/openskp
